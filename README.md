# Flashcard Examen

App sencilla de flashcards para Sistemas de Información.

## Qué incluye

- Next.js 14
- Flashcards cargadas desde `data/flashcards.json`
- LocalStorage para marcar cada tarjeta como `Bien`, `Más o menos` o `Mal`
- Filtro por tema y lista de tarjetas con estado

## Cómo usar

1. Instala dependencias:
   ```bash
   npm install
   ```
2. Levanta la app en local:
   ```bash
   npm run dev
   ```
3. Abre `http://localhost:3000`

## Despliegue en Vercel

1. Crea un repositorio en GitHub si no lo tienes.
2. Sube este proyecto al repositorio.
3. Conecta el repositorio a Vercel.
4. Vercel detecta automáticamente Next.js y despliega la app.
